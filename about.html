About Mini Games Hub

A hands-on front-end web development showcase combining HTML, CSS, JavaScript, and Bootstrap 5.

Project Overview

Mini Games Hub is an interactive, browser-based gaming suite designed to demonstrate fundamental and modern front-end web engineering skills. Players can register their session, pick from a curated collection of classic browser games, inspect the official rules, and play in real time with dynamic DOM feedback and result history.

Note on Data Persistence: This project operates entirely client-side. Scores, history, and active player objects are stored in memory and reset on page reload by intentional design.

Game Specifications & Comparison

Summary of all available mini games, difficulty levels, player support, and core JavaScript concepts exercised:

# Game Title Difficulty Level Number of Players Core Concepts Practiced
1 Number Guessing Easy 1 Player (vs Computer) Math.random(), try / catch / throw, loops, input validation

3 Memory Card Flip Medium 1 Player (Solo Challenge) JavaScript Set, array shuffling, setTimeout, 3D CSS flip
4 Tic-Tac-Toe (Bonus) Medium 2 Players (Pass & Play) Winning combinations matrix, @keyframes animation, DOM lock

Technologies & Techniques Used

This project incorporates modern web standards and architectural best practices:

Frontend Foundations

  • Semantic HTML5 (header, nav, main, section, footer) Structure
  • Bootstrap 5 via CDN (Responsive Grid, Navbar Collapse) Framework
  • Vanilla CSS3 (Custom Variables, 3D Transforms, Keyframes) Styling
  • Google Fonts Typography (Poppins) Design

JavaScript Capabilities

  • Data Structures: ES6 Set and Map Data
  • Object-Oriented Programming: Player Class OOP
  • JSON string serialization & JSON.parse() JSON
  • DOM Node Lifecycle: createElement, appendChild, remove DOM

Technology Tags

  • HTML5
  • CSS3
  • Bootstrap 5
  • JavaScript ES6+
  • DOM Manipulation
  • Regex Validation
  • 3D CSS Transforms
  • Web Audio API
  • Responsive Design

Deployment & Project Submission

This project is structured for zero-configuration static hosting on GitHub Pages or Netlify. All file assets, stylesheets, and scripts utilize relative URLs to guarantee reliable cross-platform execution.
